# wrap-ai-image-detail-illustration プロンプト例

**重要**:
- このスキルの目的は、動画や記事で使える「理解を助ける説明画像」を違う 4 案並列生成すること。
- 抽象概念をメタファーで視覚化し、情報を整理して伝える。
- **プロンプトは必ず日本語で記述すること**（日本語ラベル描画品質のため）。
- **詳細で情報量の多い画像を基本方針とする**（シンプル過ぎる図解は情報価値ゼロ）。
- engine は `.claude/skills/run-ai-images/scripts/generate.sh`（CODEX_HOME 隔離で並列安全）。

## 良い説明画像の条件

1. **メタファー** - 抽象概念を具体物で表現（キッチン＝ツール、レシピ＝手順）
2. **情報の整理** - メリット/デメリット、比較ポイントを明確に
3. **視覚要素** - アイコン、矢印、天秤などで視線誘導
4. **グラレコ風** - 手描き感がありつつ整理されたスタイル
5. **日本語テキスト** - ラベル・タイトルを日本語で

  -o output/<prefix>-01 --aspect 16:9 -n 1 --format webp \
  -p "まとめ説明画像、16:9、グラレコ風。

2. {{ポイント2}}（{{アイコン}}）- {{説明}}
3. {{ポイント3}}（{{アイコン}}）- {{説明}}

【視覚要素】

## before-after（ビフォーアフター）

変化・改善を左右または上下で対比して強調。4 バリアントは **コントラスト軸違い**（作業状態/感情/効率/スケール）で振る。

### 具体例（作業状態の対比）

```bash
bash .claude/skills/run-ai-images/scripts/generate.sh \
  -o output/diag-ai-before-after-01 --aspect 16:9 -n 1 --format webp \
  -p "ビフォーアフター説明画像、16:9、イラスト風。

【構成】左右分割、中央に大きな矢印で変化を強調

【左側 - Before】
- タイトル：「導入前」
- イラスト：散らかったデスク、山積みの書類、困った表情の人
- 状態：手作業、時間がかかる、ミスが多い、ストレス
- 色調：グレー・暗め

【右側 - After】
- タイトル：「導入後」
- イラスト：整理されたデスク、モニターにダッシュボード、笑顔の人
- 状態：自動化、効率的、正確、快適
- 色調：明るい・カラフル

【中央】
- 大きな矢印（→）で変化を表現
- 「AI導入で変わる！」のテキスト

【スタイル】左は暗く重い雰囲気、右は明るく軽い雰囲気、コントラストを強調"
```

## custom（自由記述）

上記に当てはまらない場合。ただし以下を必ず含める：

1. **具体的なイラスト描写** - 「〇〇のイラスト」ではなく詳細に
2. **レイアウト指定** - 配置を明確に
3. **スタイル指定** - タッチ、配色を指定
4. **日本語テキスト** - ラベルは日本語で

```bash
bash .claude/skills/run-ai-images/scripts/generate.sh \
  -o output/<prefix>-01 --aspect 16:9 -n 1 --format webp \
  -p "{{テーマ}}の説明画像、16:9。

【メインビジュアル】
{{詳細なイラスト描写：何が、どこに、どのように描かれるか}}

【テキスト要素】
- タイトル：{{タイトル}}
- サブテキスト：{{説明文}}
- ラベル：{{各要素のラベル}}

【レイアウト】
{{配置の詳細：中央に〇〇、左上に△△、右下に□□}}

【スタイル】
- タッチ：{{手描き風/フラット/リアル}}
- 配色：{{具体的な色指定}}
- 雰囲気：{{温かみ/クール/ポップ}}"
```

## 参考画像を使った生成

既存の良い画像のスタイルを継承する場合は engine の `--ref-image` / `--ref-instruction` を使う:

```bash
bash .claude/skills/run-ai-images/scripts/generate.sh \
  -o output/diag-new-01 --aspect 16:9 -n 1 --format webp \
  --ref-image ./reference.webp \
  --ref-instruction "このスタイル・配色・レイアウト・タッチを完全に継承。内容のみ変更" \
  -p "同じスタイルで新しい内容を作成。
{{新しい内容の詳細}}"
```
